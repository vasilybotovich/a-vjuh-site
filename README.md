# Агентство «Вжух»

Статический адаптивный лендинг с переключением светлой и тёмной темы.

## Базовый стиль «Вжух»

Этот сайт — канонический визуальный шаблон для главной страницы и отраслевых лендингов `*.a-vjuh.ru`:

- Manrope, крупная плотная типографика и скруглённые карточки;
- светлая тема по умолчанию и графитовая тёмная тема;
- жёлтый `#ffd43b` как основной акцент;
- светло-серые плашки без контрастных тёмных блоков в светлой теме;
- тонкая координатная сетка, траектории роста и умеренная анимация;
- обязательная адаптация под desktop и mobile.

Новые лендинги наследуют переменные, компоненты и сетку из `styles.css`; изменения базового визуального языка сначала вносятся сюда.

## Локальный просмотр

```bash
python3 -m http.server 8080
```

Открыть <http://localhost:8080>.
